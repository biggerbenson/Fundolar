Fundolar Plugin Changelog
========================

Version 1.5.1 - 2026-10-02
--------------------------
- Security hardening: same-site return URL validation, MarzPay webhook token auth, donate REST rate limits.
- Encrypt platform API keys; refuse plaintext OpenSSL fallback for new secrets.
- Allowlist Central and update hosts; verify optional package SHA-256 on auto-update.

Version 1.5.0 - 2026-09-05
--------------------------
- Record successful Stripe/PayPal donations reliably in the plugin and Fundolar Central.
- Fix PayPal meta updates that wiped Central donation ids.
- Upsert/create on status sync when create previously failed; hourly resync for completed rows missing Central link.

Version 1.4.9 - 2026-08-29
--------------------------
- M-Pesa / Mobile Money: show phone field when Mpesa or Mobile Money (UG) is selected; auto-select Mpesa when currency is KES.
- Donate flow no longer shows a false error while waiting for the phone prompt — MarzPay final status is webhook-driven.
- Status polling keeps waiting for approval instead of failing immediately; donors see a clear “request sent to your phone” message.

Version 1.4.8 - 2026-08-29
--------------------------
- M-Pesa / Mobile Money: wait before first status poll and ignore early "failed" responses so donors see the phone prompt instead of an instant error.
- Surface provider failure messages from MarzPay when a mobile payment does not complete.
- Round KES/UGX donation amounts to whole units before checkout.
- Updated M-Pesa and Mobile Money (UG) gateway logos (PNG).

Version 1.4.7 - 2026-08-29
--------------------------
- Fix donation form REST parsing when responses include a UTF-8 BOM (fixes immediate "Something went wrong" on M-Pesa / Mobile Money donate).
- Removed stray UTF-8 BOM from admin bootstrap file; release build strips BOM from PHP sources.

Version 1.4.0 - 2026-08-24

- Fundolar.com distribution: Central-only payments — removed own API key fields from Settings → Payments.
- Professional admin copy: how-to guide, notices, and form messages updated for Fundolar Central setup.
- Version 1.4.0 release for fundolar.com auto-updates.

Version 1.1.5 - 2026-04-30
--------------------------
- Breaking behavior change: no automatic default Fundolar Central hostname. The plugin does not call Central until you set Fundolar Central URL in Payments, or FUNDOLAR_CENTRAL_URL in wp-config.php, or the fundolar_platform_base_url filter. Prevents cURL error 6 when the old default host is not in your server’s DNS.
- connect/signed requests return a clear error if the base URL is missing; Payments screen shows “Not set” when applicable.

Version 1.1.4 - 2026-04-30
--------------------------
- Payments settings: optional "Fundolar Central URL" when the default example host is unreachable or not in DNS from the WordPress host.
- Optional wp-config.php constant FUNDOLAR_CENTRAL_URL (same purpose as the setting; saved setting wins when both are set).
- Shorter DNS/cURL error 6 hint; suggests the setting or wp-config define.
- Platform HTTP client: configurable timeout and sslverify via filters, stable User-Agent, trailing-slash path normalization for HMAC alignment with Fundolar Central.
- Activation/connect: validate api_key and signing_secret in the response; richer error messages from Central JSON.
- Fundolar Central (separate app): normalized request paths for signatures; tiered KYC (gateway sync allowed before identity approval); reject empty signing secrets on activate/register-install.
